# Changelog

Mudanças publicadas do plugin `silo-legal`, da mais recente para a mais antiga.
Alterações ainda não publicadas ficam em [`.changes/`](.changes/) e são reunidas
automaticamente quando uma versão é criada.

### Fixed

- Alinha o acesso ao Silo à validação privada e elimina confirmações de cadastro sem recibo.

## [0.2.1] - 2026-08-22

### Fixed

- Corrige o handshake interno de custo das pesquisas jurisprudenciais no Silo.

## [0.2.0] - 2026-08-21

### Added

- Publica nove skills jurídicas para intake, análise, pesquisa, aprofundamento, redação e conexão ao Silo.
- Adota changelog por fragmentos, versionamento semântico e GitHub Releases ancoradas em tags imutáveis.
- Inclui recorte versionado do CPC, handoff compartilhado, validação estrutural e bundles das sete skills do workflow cível.
